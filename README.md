# ReactionGame

Questo gioco **Reaction Game**, sviluppato in Unity per Android.  
Il giocatore deve distruggere bersagli che appaiono sullo schermo cercando di ottenere il miglior reaction time e la miglior accuracy.

## 🎮 Caratteristiche principali

- Spawn di bersagli in sequenza.
- Timer selezionabile per impostare la durata della partita.
- UI in tempo reale che mostra nemici distrutti, tempo rimanente e reaction time attuale.
- Risultati finali al termine del timer: reaction time medio, nemici distrutti e accuracy.

## 🖱️ Controlli Android

- Tap sul bersaglio → Distruggerlo
